## 首页与下载模块

---

### 功能1: Flipbook URL解析与PDF下载

- **位置**: 首页顶部输入框
- **描述**: 用户粘贴FlipHTML5书籍链接后，系统自动解析并生成高质量PDF文件供下载
- **使用场景**: 用户想要将在线FlipHTML5书籍保存为本地PDF文件以便离线阅读或打印
- **操作步骤**:
  1. 访问网站首页
  2. 在输入框中粘贴FlipHTML5书籍的完整URL（格式如：https://fliphtml5.com/username/book-id/）
  3. 点击"解析"按钮或按回车键
  4. 系统自动开始处理，显示进度条和当前处理页码
  5. 处理完成后，PDF文件自动下载到浏览器默认下载目录
- **输入内容**: FlipHTML5书籍的完整URL地址
- **界面反馈**:
  - 处理中：显示进度百分比、当前页码/总页码
  - 完成：显示"下载成功"提示，文件自动保存
  - 错误：显示具体错误信息（如"链接格式无效"、"这是私有书籍，无法下载"等）
- **完成结果**: 获得一本完整的PDF格式电子书，文件名为书籍标题.pdf
- **注意事项**:
  - 免费用户每天限制下载2次
  - 私有/加密书籍无法下载
  - 下载时间取决于书籍页数和网络速度

### 功能2: 批量下载任务管理

- **位置**: 首页下载任务列表区域
- **描述**: 用户可以同时添加多个下载任务，系统会并行处理所有任务
- **使用场景**: 用户需要下载多本不同的FlipHTML5书籍，不想等待一个完成后再开始下一个
- **操作步骤**:
  1. 在首页输入第一个书籍URL并提交
  2. 在输入框中继续输入第二个书籍URL并提交
  3. 重复添加更多任务
  4. 在任务列表中实时查看每个任务的进度
  5. 每个任务完成后会自动下载对应的PDF文件
- **输入内容**: 多个FlipHTML5书籍URL
- **界面反馈**:
  - 每个任务显示独立的状态（等待中、处理中、已完成、失败）
  - 实时显示每个任务的进度百分比
  - 已完成的任务显示"下载PDF"按钮供重新下载
- **完成结果**: 所有任务依次或并行完成，每个PDF文件自动下载
- **注意事项**:
  - 可以同时运行多个任务，无需等待
  - 失败的任务可以点击重试按钮重新处理
  - 可以删除不需要的任务

### 功能3: 热门书籍发现与浏览

- **位置**: 首页"Discovery"区域
- **描述**: 展示社区用户最常下载的热门FlipHTML5书籍，支持分页浏览
- **使用场景**: 用户想浏览其他人都在下载什么书籍，或者寻找感兴趣的阅读内容
- **操作步骤**:
  1. 滚动到首页下方的"Discovery"区域
  2. 浏览展示的书籍卡片网格（每页24本）
  3. 点击感兴趣的书籍卡片进入详情页
  4. 使用底部的分页导航切换查看更多书籍
- **输入内容**: 无需输入，浏览即可
- **界面反馈**:
  - 每本书显示封面缩略图、标题、页数、下载次数
  - 点击卡片跳转到书籍详情页面
  - 分页器显示当前页码和总页数
- **完成结果**: 找到感兴趣的书籍并进入详情页进行下载或在线阅读
- **注意事项**:
  - 书籍按下载次数排序，展示最受欢迎的资源
  - 支持多页浏览，每页加载24本书

## 在线阅读器模块

---

### 功能4: 全屏在线阅读

- **位置**: 书籍详情页点击"Read Online Now"按钮，或直接访问/read/[id]页面
- **描述**: 提供沉浸式的书籍阅读体验，支持翻页动画和高清页面显示
- **使用场景**: 用户想要在不下载的情况下直接在线浏览书籍内容
- **操作步骤**:
  1. 在书籍详情页点击"Read Online Now"按钮
  2. 阅读器全屏打开，显示书籍第一页
  3. 使用左右箭头按钮、键盘方向键、或触摸滑动进行翻页
  4. 点击"X"按钮或返回链接退出阅读器
- **输入内容**: 无需输入
- **界面反馈**:
  - 页面切换带有平滑的动画效果
  - 顶部显示书籍标题和当前页码
  - 底部显示阅读进度条
- **完成结果**: 完整阅读整本书籍，进度自动保存
- **注意事项**:
  - 支持桌面端和移动端
  - 阅读器为全屏模式，提供沉浸式体验
  - 自动保存阅读进度，下次打开时继续

### 功能5: 单页/双页模式切换

- **位置**: 阅读器顶部工具栏的书籍图标按钮（仅在宽屏显示）
- **描述**: 用户可以选择单页阅读（一次看一页）或双页阅读（一次看两页，像真实书籍一样）
- **使用场景**: 用户在大屏幕上阅读时，希望模拟真实书籍的左右页效果
- **操作步骤**:
  1. 在阅读器中打开任意书籍
  2. 点击顶部工具栏的"双页模式"按钮（书本图标）
  3. 视图立即切换为双页显示（封面除外）
  4. 再次点击切换回单页模式
- **输入内容**: 无需输入
- **界面反馈**:
  - 按钮高亮显示当前激活的模式
  - 页面布局立即调整
  - 页码显示更新为"页码范围"（如"2-3 / 50"）
- **完成结果**: 阅读体验从单页变为双页，或反之
- **注意事项**:
  - 双页模式下禁用缩放功能
  - 封面页始终单独显示
  - 仅在宽屏设备上可用

### 功能6: 页面缩放与拖拽

- **位置**: 阅读器顶部工具栏的缩放按钮组
- **描述**: 用户可以放大或缩小页面查看细节，放大后可以拖拽移动查看不同区域
- **使用场景**: 用户需要查看书籍中的小字、图片或细节内容
- **操作步骤**:
  1. 在阅读器中点击"+"按钮放大，或"-"按钮缩小
  2. 也可以使用Ctrl+鼠标滚轮进行缩放
  3. 放大后（超过100%），鼠标变为"抓手"图标
  4. 按住鼠标左键拖拽页面查看不同区域
  5. 点击"重置"按钮或按Ctrl+0恢复原始大小
- **输入内容**: 无需输入
- **界面反馈**:
  - 显示当前缩放百分比（25%-300%）
  - 鼠标悬停时显示操作提示
  - 拖拽时鼠标变为"抓取中"状态
- **完成结果**: 页面按用户指定的比例显示，可查看任意区域
- **注意事项**:
  - 双页模式下不可用
  - 切换页面时自动重置缩放
  - 支持触摸设备的捏合缩放

### 功能7: 缩略图侧边栏导航

- **位置**: 阅读器顶部工具栏的网格图标按钮
- **描述**: 显示所有页面的缩略图网格，用户可以快速跳转到任意页面
- **使用场景**: 用户想快速定位到特定页面，或预览整本书的内容结构
- **操作步骤**:
  1. 点击顶部工具栏的"缩略图"按钮（网格图标）
  2. 左侧弹出缩略图面板，显示所有页面
  3. 滚动浏览缩略图列表
  4. 点击任意缩略图跳转到该页
  5. 点击"X"按钮关闭缩略图面板
- **输入内容**: 无需输入
- **界面反馈**:
  - 缩略图面板从左侧滑出
  - 当前页的缩略图高亮显示
  - 正在加载的缩略图显示旋转动画
- **完成结果**: 快速跳转到目标页面继续阅读
- **注意事项**:
  - 打开缩略图时会自动预加载所有页面
  - ZIP格式的书籍需要逐页解压，可能略有延迟
  - 点击缩略图后立即跳转

### 功能8: 阅读进度自动保存

- **位置**: 后台自动运行，无需用户操作
- **描述**: 系统自动记录用户的阅读进度，下次打开时从上次离开的地方继续
- **使用场景**: 用户分多次阅读一本书，不想每次都从头开始
- **操作步骤**:
  1. 阅读书籍并翻页
  2. 关闭阅读器或离开页面（进度自动保存）
  3. 下次打开同一本书时，自动跳转到上次阅读的页面
  4. 顶部显示"恢复阅读进度..."提示
- **输入内容**: 无需输入
- **界面反馈**:
  - 恢复进度时显示加载提示
  - 完成后直接显示目标页面
- **完成结果**: 无缝继续上次阅读
- **注意事项**:
  - 进度保存在浏览器本地（IndexedDB）
  - 清除浏览器数据会丢失进度
  - 不同设备之间不共享进度

### 功能9: 当前页图片下载

- **位置**: 阅读器顶部工具栏的下载图标按钮
- **描述**: 用户可以下载当前正在查看的页面作为图片文件
- **使用场景**: 用户只需要保存书籍中的某一页或某几页，而不是整本书
- **操作步骤**:
  1. 在阅读器中翻到想要下载的页面
  2. 点击顶部工具栏的"下载"按钮（向下箭头图标）
  3. 图片自动下载到浏览器默认目录
  4. 双页模式下会同时下载两页
- **输入内容**: 无需输入
- **界面反馈**:
  - 下载中按钮显示旋转动画
  - 下载完成后无额外提示（使用浏览器默认下载提示）
- **完成结果**: 获得当前页的JPG图片文件（文件名：page-X.jpg）
- **注意事项**:
  - 双页模式下下载两页图片
  - 图片质量与在线阅读相同
  - 适合保存单页内容

### 功能10: 全屏模式切换

- **位置**: 阅读器顶部工具栏的全屏图标按钮
- **描述**: 将阅读器切换到系统级全屏模式，隐藏浏览器界面元素
- **使用场景**: 用户想要最大的阅读空间，不受浏览器地址栏等干扰
- **操作步骤**:
  1. 在阅读器中点击"全屏"按钮（扩展图标）
  2. 浏览器进入全屏模式（按ESC可退出）
  3. 阅读完成后再次点击全屏按钮或按ESC键退出
- **输入内容**: 无需输入
- **界面反馈**:
  - 进入全屏时浏览器界面消失
  - 阅读器占据整个屏幕
- **完成结果**: 获得完全沉浸的阅读体验
- **注意事项**:
  - 按ESC键可随时退出全屏
  - 某些浏览器可能需要用户授权

### 功能11: 键盘快捷键支持

- **位置**: 全局键盘操作
- **描述**: 提供多种键盘快捷键，提升桌面端用户的阅读效率
- **使用场景**: 用户习惯使用键盘操作，想要更快的翻页和控制速度
- **操作步骤**:
  1. 在阅读器中使用以下快捷键：
     - 右箭头（→）：Next
     - 左箭头（←）：Previous
     - ESC：退出全屏模式
     - - 或 =：放大页面
     - -：缩小页面
     - Ctrl+0：重置缩放
- **输入内容**: 键盘按键
- **界面反馈**: 页面立即响应操作
- **完成结果**: 快速完成翻页、缩放等操作
- **注意事项**:
  - 仅在桌面端有效
  - 双页模式下缩放快捷键禁用
  - 输入框聚焦时快捷键不触发

## 书籍详情模块

---

### 功能12: 书籍信息展示

- **位置**: 访问/book/[id]页面
- **描述**: 展示书籍的完整信息，包括封面、标题、描述、页数、下载次数等
- **使用场景**: 用户想要了解一本书的详细信息，再决定是否下载或阅读
- **操作步骤**:
  1. 从首页或搜索结果点击书籍卡片
  2. 查看书籍详情页的各个信息区块：
     - 左侧：封面大图、页数统计、下载次数统计
     - 右侧：书名、描述、操作按钮
  3. 滚动查看页面缩略图和相关书籍推荐
- **输入内容**: 无需输入
- **界面反馈**:
  - 封面图片悬停时轻微放大
  - 显示书籍的元数据（页数、下载量）
  - 展示部分页面缩略图预览
- **完成结果**: 全面了解书籍内容，做出下载或阅读决策
- **注意事项**:
  - 描述内容可能为空（显示默认提示）
  - 页面缩略图可能加载较慢
  - 数据来源为FlipHTML5平台

### 功能13: 页面缩略图预览

- **位置**: 书籍详情页下方区域
- **描述**: 展示书籍所有页面的缩略图，用户可以预览内容
- **使用场景**: 用户想快速浏览整本书的内容结构，或查找特定页面
- **操作步骤**:
  1. 在书籍详情页向下滚动到"页面预览"区域
  2. 浏览展示的缩略图网格
  3. 点击"在线阅读"按钮进入完整阅读器
- **输入内容**: 无需输入
- **界面反馈**:
  - 缩略图以网格形式展示
  - 每张缩略图显示页码
  - 悬停时显示放大效果
- **完成结果**: 预览书籍内容，了解整体结构
- **注意事项**:
  - 缩略图质量低于在线阅读
  - 大量页面时可能需要滚动加载
  - 仅供预览，不可下载

### 功能14: 相关书籍推荐

- **位置**: 书籍详情页底部"Related Books"区域
- **描述**: 基于当前书籍的主题相似度，推荐其他相关书籍
- **使用场景**: 用户读完一本书后，想发现更多类似主题的书籍
- **操作步骤**:
  1. 在书籍详情页滚动到底部
  2. 查看"Related Books"区域
  3. 浏览推荐的书籍卡片
  4. 点击感兴趣的书籍进入其详情页
  5. 如果有更多推荐，点击"View All"查看完整列表
- **输入内容**: 无需输入
- **界面反馈**:
  - 显示推荐书籍数量和相似度说明
  - 每本书显示封面、标题、页数
  - "View All"链接在有更多推荐时显示
- **完成结果**: 发现并访问相关书籍
- **注意事项**:
  - 推荐基于标题和描述的语义相似度
  - 不包含当前正在查看的书籍
  - 推荐数量默认显示6本

### 功能15: 书籍操作按钮组

- **位置**: 书籍详情页右侧操作区域
- **描述**: 提供三个主要操作：在线阅读、下载PDF、分享书籍
- **使用场景**: 用户决定要对这本书执行什么操作
- **操作步骤**:
  1. 查看书籍信息后，选择以下操作之一：
     - 点击"Read Online Now"：进入在线阅读器
     - 点击"Download as PDF"：跳转到下载页面并自动开始下载
     - 点击"Share"：打开分享弹窗
  2. 根据选择执行相应操作
- **输入内容**: 用户的选择
- **界面反馈**:
  - 按钮悬停时高亮并放大
  - 点击后立即跳转或弹出窗口
- **完成结果**: 开始阅读、下载或分享书籍
- **注意事项**:
  - 下载功能受每日限额限制
  - 在线阅读需要加载书籍数据
  - 分享功能支持多种渠道

## 博客与内容模块

---

### 功能16: 博客文章列表

- **位置**: 访问/blog页面
- **描述**: 展示所有博客文章的列表，按发布日期倒序排列
- **使用场景**: 用户想阅读关于Flipbook下载、使用技巧、产品更新等相关文章
- **操作步骤**:
  1. 访问网站的博客页面
  2. 浏览文章列表（显示标题、描述、发布日期）
  3. 点击感兴趣的文章标题进入全文
- **输入内容**: 无需输入
- **界面反馈**:
  - 文章卡片显示标题、摘要、日期
  - 悬停时卡片显示阴影效果
  - 文章按时间倒序排列（最新的在前）
- **完成结果**: 找到并阅读感兴趣的文章
- **注意事项**:
  - 博客内容用于SEO和知识分享
  - 包含使用教程、产品介绍、行业动态等
  - 支持Markdown格式渲染

### 功能17: 博客文章阅读

- **位置**: 访问/blog/[slug]页面
- **描述**: 完整展示单篇博客文章的全文内容
- **使用场景**: 用户想要详细阅读某篇文章的内容
- **操作步骤**:
  1. 从博客列表点击文章标题
  2. 阅读文章正文
  3. 滚动浏览完整内容（可能包含代码示例、图片等）
  4. 使用浏览器返回按钮回到列表
- **输入内容**: 无需输入
- **界面反馈**:
  - 文章标题和元数据（发布日期等）
  - 正文内容使用优化的排版格式

  - 阅读器全屏填充iframe容器
  - 不显示网站的导航栏和页脚
  - 提供"Open on site"链接打开完整版
- **完成结果**: 第三方网站内嵌入可交互的阅读器
- **注意事项**:
  - 嵌入页不参与SEO索引
  - 支持响应式尺寸
  - 可配置起始页和显示选项

### 功能26: ZIP格式书籍支持

- **使用场景**: 某些FlipHTML5书籍使用ZIP格式存储资源，系统自动兼容
- **操作步骤**:
  1. 用户提交包含ZIP资源的书籍URL
  2. 系统自动识别ZIP格式
  3. 下载并解压ZIP文件
  4. 提取其中的页面图片
  5. 生成PDF或提供在线阅读
- **输入内容**: 书籍URL（系统自动识别格式）
- **界面反馈**:
  - 处理过程与普通书籍相同

- **完成结果**: 无论书籍使用何种格式，都能正常下载或阅读
- **注意事项**:
  - 处理时间可能略长（需要解压）
  - 对用户体验透明
  - 自动处理密码保护的ZIP（如有）

### 功能27: 私有书籍保护

- **位置**: 下载流程中的安全检查
- **描述**: 检测并拒绝处理加密或私有的FlipHTML5书籍，尊重版权
- **使用场景**: 用户尝试下载受保护的书籍时，系统提示无法处理
- **操作步骤**:
  1. 用户提交书籍URL
  2. 系统检查书籍的访问权限
  3. 如果是私有/加密书籍，显示错误提示
  4. 下载任务标记为失败
- **输入内容**: 书籍URL
- **界面反馈**:
  - 显示"This is a private book and is not available for download"
  - 任务状态变为"失败"
- **完成结果**: 保护版权，不处理未授权内容
- **注意事项**:
  - 这是版权保护机制
  - 用户需要书籍所有者的授权
  - 仅处理公开可访问的书籍

流程7: 继续阅读上次未读完的书
访问/history页面 -> 查看阅读历史列表 -> 找到想继续的书 -> 点击"继续"按钮 -> 从上次离开的页码开始阅读

流程8: 查看相关书籍推荐
访问书籍详情页 -> 滚动到页面底部 -> 查看"Related Books"区域 -> 浏览推荐书籍 -> 点击感兴趣的书籍进入其详情页
